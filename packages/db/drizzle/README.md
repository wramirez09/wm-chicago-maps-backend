# Migrations

Generated by `pnpm db:generate` (drizzle-kit) from `src/schema/`, applied by
`pnpm db:migrate` locally and by Fly's `release_command` in production.

Two hand edits are required after every `generate` because drizzle-kit does
not understand PostGIS custom types:

1. The first migration creates the `postgis` and `pg_trgm` extensions at the top.
2. drizzle-kit quotes `geography(Point,4326)` as an identifier; strip the quotes:
   `sed -i -E 's/"(geography\([A-Za-z]+,4326\))"/\1/g' drizzle/*.sql`

Never use `drizzle-kit push` against this schema.
